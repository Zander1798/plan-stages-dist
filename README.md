# Plan Stages — QGIS plugin repository

Stage-by-stage fibre planning for QGIS 4, with operator approval after every stage (Velocity Fibre).

## Install

1. QGIS: **Plugins > Manage and Install Plugins > Settings**, press **Add...**
2. Name `Plan Stages`, URL `https://raw.githubusercontent.com/Zander1798/plan-stages-dist/main/plugins.xml`, OK.
3. **All** tab: search **Plan Stages**, **Install Plugin**.

New versions then appear under **Upgradeable** in the same dialog.

This repository holds only the built plugin; it is published from the private source repository.
